# Промпт для первого запуска агента

Прочитай AGENTS.md в корне проекта и действуй по нему. Изучи INDEX.md и файл пожеланий docs/wishes.md. Помоги уточнить пожелания и предложи структуру ТЗ. Создавай документы по мере согласования со мной.

Ведение индекса, назначение постоянных ID требованиям, настройку списка нормативных документов в governance.json и запуск валидатора выполняй самостоятельно. Не требуй от меня заранее готового списка документов, кодов требований или специального оформления пожеланий.

Если пожелания пока пусты, попроси меня описать, что я хочу получить. Не придумывай требования и не добавляй демонстрационные записи. Исходные пожелания не перезаписывай без согласования.

Проверь доступность Python 3.9+ и возможность запуска проверок. Если среда требует разрешения на выполнение команд или Python отсутствует, сообщи об этом. Не выдавай непроведённую проверку за успешную.

Если в проекте уже есть документация или одноимённые служебные файлы, сначала изучи их и предложи согласованное объединение без перезаписи существующего содержимого. По завершении изменений проверь индекс валидатором и сообщи фактический результат.
