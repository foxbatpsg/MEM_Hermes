# История изменений ТЗ MiniMem-1

## Редакция v1.6
Правки v1.6: раздел X перенесён в 3.7; режимы стали нормативными; event_id сделан стабильным по логическому ходу; content_hash вычисляется до обрезки; redaction использует детерминированные placeholder'ы; журнал пишется атомарно под блокировкой; добавлено правило вложенного mm:begin; SQLite разделён на memory_fts и memory_meta; добавлены capture_guard, journal_cursors и полная схема служебного слоя; индексатор стал инкрементальным; catch-up превращён в state machine; правило 2 уплотнения отключено по умолчанию; добавлены max_search_terms, санитизация вставки, детерминированный выбор дайджеста, расширенная наблюдаемость и тесты MM-51+.

## Редакция v1.5 и ранее
Правки v1.5 уточняют поиск по замечаниям к v1.4: механизм назван усечением основы, а не стеммингом; порог переименован в `search_score_threshold` с явно заданным направлением сравнения; добавлен тест 50; trigram отвергнут.

Правки v1.4 внесены по результатам проверки FTS5 на русском тексте: построение поискового запроса (разделы 9, 12, 20) и тесты 48–49.

Правки v1.3 внесены по результатам сверки с установленным Hermes: установка и регистрация хуков (новый раздел 26), определение сжатия контекста, состав события хода.

Правки v1.1 внесены по документу «MiniMem-1 - План правок ТЗ».

Правки v1.2 внесены по замечаниям к v1.1: восстановление снятых записей после пересборки индекса, поведение Возврата после сжатия контекста Hermes, точный дубль в пределах одного проекта.

## Методологические заимствования
Дополнения §23 (разделы «Номера и статусы тестов», «Обязательные номера») и §25 (п. 11–13) — заимствования из системы индексации документации с перекрёстными проверками: обязательные номера, статусы записей, правило фактического результата.
